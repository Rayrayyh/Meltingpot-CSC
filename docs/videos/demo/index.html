Every class takes notes.
Almost none of it reaches the rest of the class.
meltingpot
One shared vault for each class.
MeltingPot gathers the notes a class shares into one place everyone can study from.
How it is built
The app

Next.js and React

One web app for students and teachers, with Clerk for sign-in.

The data

Supabase

Postgres with row-level security on every table, plus file storage.

The AI

Google Gemini

Drafts organized notes, summaries, flashcards, practice tests and the readout.

A person approves every note and every correction.
